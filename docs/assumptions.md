# Assumptions

Values used where the reference model or a datasheet doesn't give one.

| Assumption | Value | Replace when |
|---|---|---|
| Chiller size | Each chiller carries about half the plant load (about 1,000 kW total) | Chiller selections are made |
| Cooling tower and heat exchanger performance | Typical values, giving a free cooling switch point of about 2.5°C wet-bulb | Tower and heat exchanger selections are made |
| Temperature sensor distance after a tee | 10 pipe diameters | Manufacturer or project spec says otherwise |
| Flow meter straight pipe | 5 pipe diameters before, 2 after | Meter datasheet is available |
| Loop pressure sensor location | At CRAH-1, the far air handler | Real piping design is done |
| Device power draw, panel heat, terminal sizes | Typical catalog values | Real parts are selected |
| Pipe, duct, equipment and room sizes | DN200 mains, DN150 branches, DN125 to the air handlers, 1000 x 500 mm duct, 20 x 12 m room | Mechanical design is available |
